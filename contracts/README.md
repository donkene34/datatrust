# contracts/

Smart contracts Solidity du projet Data Trust & Insights.

Contiendra le contrat de certification de datasets (voir Blueprint §4 pour le schéma `DatasetCertificate`) : `datasetId`, `owner`, `datasetHash`, `ipfsCID`, `metadataHash`, `version`, `qualityScore`, `timestamp`.

Développement prévu via Remix (démarrage) ou Hardhat (si des tests automatisés sont nécessaires en Phase 3).
